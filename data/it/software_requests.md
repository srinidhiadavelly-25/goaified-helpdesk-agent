# Software Installation and Request Policy (Synthetic Sample)

Policy ID: IT-004 | Owner: IT Operations

## 1. Approved software
Approved software can be installed by yourself from the **Company Portal** app (Windows) or **Self Service** app (Mac) without admin rights. Examples: Microsoft Office, Slack, Zoom, Python, VS Code, PyCharm Community, Git, Postman.

## 2. Requesting new software
1. Raise a **Software Request** ticket in the IT Service Desk portal (itsupport.goaified.example).
2. Include the software name, version, business reason and whether a paid licence is needed.
3. Your manager approves the request, then IT Security reviews it.
4. Standard turnaround is **3 working days**; paid licences can take up to 10 working days.

## 3. Prohibited software
Pirated software, torrent clients, personal VPNs, remote-access tools not provided by IT, and browser extensions that read all website data are prohibited.

## 4. Admin rights
Local admin rights are not given by default. Temporary admin access (maximum 24 hours) can be requested with manager approval.
